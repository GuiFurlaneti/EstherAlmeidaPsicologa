# Esther Almeida | Psicóloga

Landing page institucional para Esther Almeida, psicóloga (CRP 06/226371) — psicoterapia online para adultos.

🔗 **Site publicado:** https://guifurlaneti.github.io/EstherAlmeidaPsicologa/

## Tecnologias

- HTML5 + CSS3 (sem frameworks)
- JavaScript vanilla (menu mobile)
- Google Fonts: Fraunces (serif), Caveat (script), Jost (sans-serif)

## Estrutura

- `index.html` — página única (hero, sobre, atendimento, como funciona, contato)
- `styles.css` — identidade visual (terracota + verde-sálvia + creme)
- `script.js` — menu mobile
- `assets/img/` — fotos da profissional (adicionar aqui)

## Identidade visual

Paleta e tipografia extraídas da identidade já usada pela profissional no Instagram (@estheralmeida.psi): tons terrosos/acolhedores, tipografia serifada elegante combinada com script para destaques, ilustrações botânicas em line-art.

## Conformidade ética

Conteúdo respeita a Nota Técnica CFP nº 01/2022 (sem promessa de cura, autoexaltação ou exibição de pacientes) — exibe nome completo e número do CRP.
